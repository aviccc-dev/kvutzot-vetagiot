# 0.10.0 — טאבים בתוך הקובץ, עם מאפיינים (10.11.2026)

"הכוונה היתה שיש שלושה טאבים: בראשון זורקים רעיונות ומעט מסדרים; בשני מוסיפים רעיונות ויותר מסדרים, ולכן אפשר לערבב גם: לקשר בלי סדר, להשאיר תלושים וכיוצא; בשלישי יש מפה המחויבת לסדר מוחלט."
"צריך לאפשר מאפייני טאב." "כמה טיוטות לכיווני חשיבה."

## מה יש
- **כמה טאבים מכל סוג בקובץ.** בשורת התצוגות מופיעים הטאבים בשמם. נגיעה עוברת לטאב. נגיעה בטאב הפעיל, או לחיצה ארוכה, פותחת את התפריט שלו:
  - מאפיינים…
  - שנה שם
  - העתק: טאב נוסף עם אותו תוכן, מיד אחריו
  - הזז ימינה / שמאלה
  - הסתר: נשאר בקובץ
  - מחק: את האחרון מסוגו לא מוחקים
- **"+ טאב"**: טאב חדש מאחד שלושת הסוגים.
- **"☰ מוסתרים"**: מחזיר טאב מוסתר.
- **מאפייני טאב** (כל שורה מראה את המצב, ונגיעה משנה):
  - **בכל טאב:** שם; הערה (מופיעה בשורה העליונה); עריכה: מותרת, או נעול לקריאה בלבד (🔒 ליד השם).
  - **התחלת נושא:** סוגי חלקים מותרים (כתבן, גיליון, פנקס); מחיקה בפנקס: פס ומחיקה / רק פס, כך שהכול נשאר / רק מחיקה.
  - **סיעור מוחות:** מותר לחבר בקווים, או לא.
  - **מפה:** סדר מוחלט (כן: אין "פריט תלוש חדש", ובשורה העליונה מופיע כמה לא במקומם); כיוון: לפי התוכנה / מלמעלה למטה / מימין לשמאל; תצוגה: לפי התוכנה / גרפית / טקסט.
- **"העבר למפה" מסיעור המוחות:**
  - אם יש כמה מפות, בוחרים לאיזו.
  - במפה בסדר מוחלט בוחרים מקום בעץ: אב מרשימה לפי העץ, ואם יש לו כמה חלוקות, גם את החלוקה.
  - במפה בלי סדר מוחלט הפריט נכנס כתלוש.
- **בתפריט ⋯ של פריט:** "הצב בעץ…" לתלוש, ו"העבר למקום אחר בעץ…" לפריט אחר.
- **מפה נעולה:** נגיעה ב"פתח" מציגה את המידע על הפריט לקריאה בלבד.
- **תגיות ובחינות משותפות לכל המפות שבקובץ.**
- **קובץ חדש:** המפה בסדר מוחלט.
- **קבצים קיימים:** נפתחים עם שלושה טאבים כמו קודם. הסימון "מוחלטת" עובר לטאב המפה.

## בקובץ
- `<kvSheets>` בראש הקובץ: `<kvSheet id kind name note locked hidden …>`, ובתוכו התוכן של הטאב.
- המפה הראשונה נשמרת בגוף הקובץ (`body="yes"`), כמו OPML רגיל.
