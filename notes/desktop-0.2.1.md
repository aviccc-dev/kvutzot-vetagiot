# קבוצות ותגיות למחשב — 0.2.1 (11.11.2026)

## למה 28 מגה, ומה עכשיו
- הקוד של התוכנה שוקל כ-0.2 מגה, כמו בטלפון. כל השאר (כ-27 מגה) הוא Java עצמה. אנדרואיד כולל Java בתוכו, וחלונות לא.
- המשתמש הציע: "אולי לבדוק אם מותקן ג'אווה, אז אין צורך להתקין שוב."

## שלושה קבצים בדף ההורדה
- **`…-small.zip` (כ-0.2 מגה):** מפעיל קטן (`KvutzotVeTagiot.exe`) ו-`kvutzot.jar`. פותחים את ה-ZIP לתיקייה ומפעילים את ה-EXE.
  - המפעיל מחפש במחשב Java בגרסה 11 ומעלה, ומפעיל איתה את התוכנה.
  - הוא מחפש במשתנה JAVA_HOME, ב-PATH, ברישום של חלונות (Oracle, Temurin, Microsoft, Zulu ועוד), ובתיקיות ההתקנה המקובלות.
  - אם אין Java, או שהיא ישנה (למשל 8), הוא מציע שתי דרכים:
    - להתקין Java פעם אחת (חינם, Temurin), ואז להפעיל שוב.
    - להוריד את הגרסה המלאה.
- **`…-full-setup.exe` / `…-full-portable.zip` (כ-28 מגה):** כמו קודם, עם Java בפנים.

## עוד
- התוכנה נבנית עכשיו ל-Java 11 ומעלה (קודם 17), כדי שתעבוד עם יותר התקנות קיימות.
- ב"אודות" כתוב על איזו Java התוכנה רצה: הכלולה, או זו שמותקנת במחשב.
- **בדיקה בבנייה:** המפעיל נבנה על חלונות ומורץ במצב בדיקה. הבנייה נכשלת אם הוא לא מוצא את ה-Java שמותקנת במכונה.

## הוחלט בלי לשאול (הסקה של Claude, לא של המשתמש)
- **כשאין Java, המפעיל לא מוריד ומתקין לבד.** הוא שולח לדף ההתקנה הרשמי, או לגרסה המלאה. קובץ EXE קטן ולא חתום שמוריד ומריץ תוכנות עלול להיחשד אצל אנטי־וירוס.
- **המפעיל נכתב ב-C#**, ש-‎.NET Framework שלו קיים בכל חלונות 10 ו-11. כך אין חלון שחור של cmd.
