# ספר ההגיון לרמח"ל — קובץ מפה

`ספר ההגיון.xml` — כל הספר בעץ אחד, נבנה ב-`build.py` מתוך `gen1.py`–`gen3.py`:
`python3 build.py "ספר ההגיון.xml"`

- **ראש העץ:** מלאכת ההגיון. **החלוקה הראשונה** (של המשתמש): עסק ההגיון (פרקים א–ג), ההגיון עצמו (ד–כב), הסדר (כג).
- **שאר החלוקות לפי הספר**, כל אחת עם הבחינה שלה; מושג שהספר מחלק כמה פעמים — כמה חלוקות במקביל.
- **מידע לכל פריט:** הגדרה, פירוש, דוגמה, כלל, מקור (פרק וסעיף), ולפעמים חיוב / תנאי / סגלה / סדר החקירה; "הערה" — החלטות מבנה של Claude.
- **הנוסח** מילה במילה מ"ההגיון ללא ניקוד.txt" שבפרויקט (לפעמים קטע רצוף מתוך משפט).
- **בחינות:** שמותיהן ממילות הספר בחלוקה; אותו זוג מילים — בחינה אחת (רחוק וקרוב ×3, עצמי ומקרי ×4, עקרי וטפל ×3, פשוט ומרכב ×3 ועוד).
- 291 פריטים, 42 בחינות.
